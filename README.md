# Furri

[Открыть приложение](https://w0rkl.github.io/furri/)

Мастерская фурсон: 10 видов, 5 поз, цвета, узоры, эмоции и аксессуары. Галерея из 15 оригинальных сгенерированных иллюстраций. Светлая и тёмная темы; выбор сохраняется в браузере.

Статическое приложение без сервера и аналитики. Профили, персонажи и настройки остаются в localStorage текущего браузера. Локальный профиль не является защищённым аккаунтом и не синхронизируется между устройствами. Иллюстрации галереи и редактируемые векторные персонажи — разные форматы.

GitHub Pages публикует корень ветки codex/furri-pages. Установка зависимостей не нужна.
